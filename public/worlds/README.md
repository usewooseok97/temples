# 월드 파일 넣는 곳

Marble에서 내보낸 파일을 월드마다 폴더를 만들어 넣고, `worlds.json`에 등록합니다.

```
public/worlds/my-temple/world.spz      ← Gaussian splat (.spz 또는 .ply)
public/worlds/my-temple/collider.glb   ← Collider mesh
public/worlds/my-temple/pano.png       ← (선택) 360 panorama
```

`worlds.json` 항목 예시와 선택 항목 설명은 프로젝트 루트의 README.md를 보세요.
